# User Account Security and Access Policy

## Page 1

User Account Security - Password and Lockout Rules
User passwords must contain at least 12 characters and include both uppercase and numeric characters.
Accounts are automatically locked after 5 consecutive failed authentication attempts.
Account unlock requests require email confirmation or identity verification with support.
Session tokens expire automatically after 15 minutes of inactivity for agent security.

## Page 2

Multi-Factor Authentication and Security Alerts
Multi-factor authentication (MFA) is strictly mandatory for all administrative and billing accounts.
Changes to email addresses or payment profiles trigger an instant automated security alert.
If unauthorized access is suspected, agents can immediately revoke all active refresh tokens.
Support agents will never request your account password under any circumstances.
